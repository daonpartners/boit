보잇 BOIT 개인정보처리방침

공고일 2026년 11월 23일 · 시행일 2027년 1월 3일

다온파트너스(이하 "회사")는 보잇을 운영하면서 ① 회원 정보는 개인정보처리자로서, ② 회원이 입력한 고객정보는 회원으로부터 위탁받은 수탁자로서 처리합니다.

1. 처리하는 개인정보

구분 항목 수집 방법
회원 가입 (필수) 이름, 휴대폰 번호, 이메일, 비밀번호(암호화) / (선택) 소속 회사·지점 가입 화면
회원 이용 이용권·결제 기록(결제일·금액·결제수단, 입금자명), 충전금 내역, 청구 발송 기록(보험사·일시·결과·장수), 접속 기록·IP·기기 정보 이용 중 자동 생성
개인페이지 (선택, 공개) 이름, 사진, 연락처, 소속, 소개글 회원 입력 — 누구나 볼 수 있음
연결 서비스 솔라피 연결 정보(토큰), 연결된 솔라피 계정 이름, 발신번호 회원 연결 (서버 암호화)
고객정보 (위탁) 이름, 휴대폰, 생년월일·성별, 주소, 직업, 계약·담보 정보, 상담·활동 기록 회원 입력, 보장분석 파일
보험금 청구 (위탁) 고객·계약자·피보험자·법정대리인의 이름·관계·휴대폰, 주민등록번호, 사고·진료 내용, 청구 서류 사진, 서명, 보험금 수령 계좌 회원 입력, 고객 서명 링크
자동조회 (기능 제공 시, 고객 본인 인증) 이름, 생년월일, 휴대폰, 통신사 / 내보험다보여 아이디·비밀번호(저장 안 함) / 조회 결과: 진료내역, 의료비 자료, 보험계약·담보 정보 고객 본인 입력
상담 신청 페이지 이름, 휴대폰, 관심 상품 고객 본인 입력

2. 처리 목적

회원 확인·로그인, 서비스 제공, 이용권·충전금 결제와 세금계산서·현금영수증 발행, 보험금 청구서 작성·발송과 결과 알림, 회원 지시에 따른 고객관리·문자 발송, 자동조회 결과 표시, 문의·장애 대응, 부정 이용 방지, 서비스 개선 통계

3. 보유 기간

항목 보유 기간
회원 정보 탈퇴 시까지 (아래 법정 보관 제외)
고객정보 회원이 삭제하거나 탈퇴 후 30일 이내 파기
주민등록번호·청구 서류 사진 발송 완료 5분 뒤 파기 (대기·실패·취소 건 최대 7일)
주민번호 뒷자리 보관 기능 (회원 선택, 고객 동의 시) 회원·고객이 삭제할 때까지, 탈퇴 시 파기
보험금 수령 계좌 (고객 동의 시) 고객정보 삭제 시까지 (암호화)
진료내역 (고객 별도 동의 시) 6개월 뒤 자동 삭제 (암호화)
내보험다보여 조회 결과 (서버 보관본) 회원이 고객에 넣으면 즉시, 아니면 30일 뒤 자동 삭제
청구 내역 고객·보험사·일시·결과·장수·휴대폰만 남김, 고객정보 삭제 시까지

법령에 따른 보관: 계약·청약철회·대금결제 기록 5년, 소비자 불만·분쟁 기록 3년(전자상거래법 시행령 제6조) / 접속 기록 3개월(통신비밀보호법 시행령 제41조) / 세금 관련 장부·증빙 5년(국세기본법 제85조의3)

4. 민감정보·고유식별정보

  • 건강정보(진단서, 진료내역)는 민감정보로, 고객의 별도 동의를 받아 처리합니다(개인정보 보호법 제23조).
  • 주민등록번호는 보험금 청구서 작성·발송을 위해 일시 처리하며 3항 표의 기간 뒤 파기합니다(개인정보 보호법 제24조의2).
  • 주민번호 뒷자리 보관은 회원이 고르는 선택 기능으로, 회원이 고객 동의를 받은 경우에만 회원 기기에서 암호화된 값으로 보관합니다. 회사는 그 값을 열람할 수 없으며, 보관에 대한 책임은 회원에게 있습니다(이용약관 제11조).

5. 제3자 제공

회사는 개인정보를 외부에 제공하지 않습니다. 다만 회원이 보험금 청구를 보내면, 회원이 고른 보험회사에 청구서와 첨부 서류가 팩스로 전달됩니다. 그로우사업부 등 소속 관리자에게 회원의 고객정보를 보여 주지 않습니다.

※ 솔라피(㈜누리고)는 회사의 위탁업체가 아니라 회원이 직접 가입한 서비스입니다. 회원이 문자를 보내면 받는 사람 번호와 내용이 회원의 솔라피 계정으로 전달됩니다.

항목 내용

현재 고객정보는 서울 리전에 저장됩니다.

8. 파기

보유 기간이 끝나거나 목적이 달성되면 지체 없이 파기합니다. 전자 파일은 복구할 수 없게 삭제하고, 출력물은 분쇄합니다.

9. 정보주체의 권리

  • 회원: 서비스 안에서 직접 열람·정정·삭제·탈퇴할 수 있고, 보호책임자에게 요청할 수도 있습니다.
  • 고객: 고객정보의 처리자는 담당 회원이므로 담당 설계사에게 열람·정정·삭제·처리정지를 요청할 수 있습니다. 회사로 요청이 오면 담당 회원에게 전달하고 처리를 돕습니다.

10. 안전성 확보 조치

  • 주민등록번호·보험금 수령 계좌·진료내역 암호화 저장
  • 고객정보는 해당 회원 계정만 볼 수 있게 데이터베이스에서 행 단위로 접근 제한
  • 청구 서류·주민등록번호 자동 파기
  • 외부 서비스 비밀키는 화면(브라우저)이 아닌 서버에 보관
  • 오류 기록(로그)에 이름·연락처·주민등록번호·조회 결과를 남기지 않음

11. 자동 수집 장치

광고·분석용 쿠키(Meta 픽셀, Google 애널리틱스 등)를 쓰지 않습니다. 로그인 유지와 화면 설정 저장을 위해 브라우저 저장소를 씁니다.
