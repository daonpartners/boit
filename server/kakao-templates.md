# 보잇 카카오 알림톡 템플릿 (등록용 문안 · 2026-11-23)
카카오 비즈니스 채널 '보잇 BOIT' → 솔라피 콘솔 [카카오 알림톡 › 템플릿 등록]에 아래 문안 그대로 등록.
승인되면 템플릿 ID를 boit_config 에 넣으면 서버가 알림톡으로 바꿔 보냄 (실패하면 문자로 대신 보냄).

| boit_config 키 | 용도 | 템플릿 문안 |
|---|---|---|
| kakao_pfid | 채널 ID (솔라피 pfId) | — |
| kakao_tpl_lead | 설계사에게: 상담신청 접수 | [보잇] #{고객명} 고객의 #{내용}이 접수되었습니다.\n보잇 앱 상담관리에서 확인해 주세요. |
| kakao_tpl_claim | 설계사에게: 고객 청구 접수 | [보잇] #{고객명} 고객의 #{내용}이 접수되었습니다.\n보잇 앱 보상청구 화면 맨 위에서 확인해 주세요. |
| kakao_tpl_ok / kakao_tpl_bad | 팩스 결과 (fax-watch, 기존) | 기존 등록 문안 |

- 메시지 유형: 기본형(정보성). 광고 문구 넣지 않음.
- 변수: #{고객명} = 이름 가운데 가림(홍*동), #{내용} = "보험금 청구 접수 (서류 3장)" / "상담신청 (암·운전자)"
